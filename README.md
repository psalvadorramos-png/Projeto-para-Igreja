# Projeto de Extensão – Desenvolvimento de Site para Igreja

## 📖 Sobre o projeto

Este projeto foi desenvolvido como atividade de extensão da faculdade, com o objetivo de aplicar conhecimentos de desenvolvimento web na criação de um site institucional para uma igreja.  

O site foi desenvolvido utilizando HTML e CSS, apresentando um design moderno, organizado e responsivo, buscando melhorar a comunicação da igreja com a comunidade e facilitar o acesso às informações principais da instituição.

---

## 🎯 Objetivo

O objetivo do projeto é disponibilizar uma plataforma digital informativa e acessível, permitindo que visitantes conheçam mais sobre a igreja, suas ações e atividades.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Git e GitHub

---

## ✨ Funcionalidades

O site possui:

- História da igreja
- Informações sobre os padres ministrantes
- Ações internas
- Ações sociais
- Redes sociais
- Endereço e localização
- Layout responsivo
- Design baseado nas cores da igreja
- Estrutura visual em formato “zig-zag” para melhor experiência do usuário
- Botões clicáveis

---

📌 Comportamento esperado

Espera-se que o site apresente uma navegação simples, intuitiva e responsiva, permitindo que os usuários acessem facilmente todas as informações disponibilizadas pela igreja.

O layout foi desenvolvido em um formato dinâmico em “zig-zag”, alternando a disposição dos conteúdos para tornar a navegação mais moderna e visualmente agradável. Além disso, o design foi elaborado com base nas cores utilizadas pela própria igreja, fortalecendo sua identidade visual.
